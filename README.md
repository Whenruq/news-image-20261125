# Sum up 25 November's world news in one image

A classic newspaper front page for Wednesday, 25 November 2026. The lead story
covers Shenzhou-24 carrying Muhammad Zeeshan Ali — the first Pakistani in
orbit — to China's Tiangong station, illustrated with a drawn rocket and
station scene. Below it sit the Asian tech share sell-off (Kospi −6.2%,
Nikkei 225 −2.8%), the freeing of all hostages at the Exito supermarket in
Cartagena, the Australia–Solomon Islands treaty signed in Canberra, and the
Bogor mine disaster at Pongkor (9 dead, 17 still trapped), with a short
ticker of three more Wednesday headlines along the bottom.

Run `node main.ts` to copy `entry.png` into `MAKEFUN_OUTPUT_DIR` (or
`/output` when the variable is unset).
